Entry for the [make.fun](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) bounty **One Sentence for a Traveler from 1800**.

`main.ts` (Node 22) writes one sentence — explaining the modern internet to someone arriving from 1800, in words and pictures they could already know — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

The entry (193 characters, one sentence):

> Imagine one road joining every post office and library in the world, so a letter you write at breakfast is read across the sea before dinner, and the book you seek lies open before you at once.
